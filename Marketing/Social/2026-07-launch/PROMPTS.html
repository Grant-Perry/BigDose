How to use

  1. Still: Nano Banana Pro → set aspect in UI → paste Still → attach refs → confirm button says Generate — Unlimited.
  2. Run Concept A at 4:5 first. If it works, re-run the same Still at 9:16, 1:1 and 16:9 (only change the ratio in the UI).
  3. Storyboard: one Still at 16:9 (6-panel sheet). Inspect before Kling.

  6. Do not run these through MCP — that spends credits. Web Unlimited only.

CapCut checklist

Do this after Kling. Ring never moves because it never went through Kling.

1) Assets
   - Plate video: Kling output from Still E-blank (black phone screen)
   - UI still: your approved Still E with correct BigDose UI + copy
     OR crop just the phone screen from that still / from active-session.png

2) Timeline
   - CapCut (or Final Cut): new project, same aspect as the plate
   - Put Kling plate on V1 full duration
   - Put UI still (or screen crop) on V2 above it

3) Fit the screen
   - Scale / position the UI layer so it sits exactly inside the phone glass
   - Soften edges slightly if needed (tiny feather / mask)
   - CapCut: Animation → Tracking on the UI layer if the hand drifts; pin to phone screen
   - If tracking fights you: keep camera lock strong in Kling and hand-keyframe 2–3 positions

4) Export
   - Confirm: waves move, hand breathes, gold ring NEVER spins, numbers NEVER change
   - Export 1080 (or 4K) · same aspect · ready for IG / FB / X
